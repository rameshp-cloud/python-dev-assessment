\## How to Run



Make sure Python is installed.



Run the individual Python files from the project directory:



```powershell

python hello.py

python bad\_style.py

python dsa\_challenges.py

python book\_store.py

python debug\_errors.py

python api\_client.py



```



For the API task, the `requests` library is required:



```powershell

python -m pip install requests

```
